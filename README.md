# Sources

- `maquette-resa-guides.jsx` — composant React unique contenant toute la maquette
  (données de démonstration, logique métier, trois vues).
- `mount.jsx` — point d'entrée qui monte le composant dans la page.
- `tailwind.config.js` / `input.css` — configuration des styles.

La commande de compilation est décrite dans le README à la racine du dépôt.
